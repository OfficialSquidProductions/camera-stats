# Shot Reporter 0.1.1 alpha 3

Camera Stats is now **Shot Reporter**, across Mac, iPhone/iPad, Windows, Android, exports, the download site, and public source. This is the same local reporting field alpha, with the same MIT license, Squid Productions suite icon style and fictional The Last Light demo.

Existing app IDs, report storage, SQLite schema, signing keys, Windows UpgradeCode and `.camreport` schema 1 remain compatible. Existing reports are never renamed or rewritten merely because the app has a new name. Windows and Android downloads are manually installed; no updater was added. Keep an independent report backup.

- Mac: universal Intel / Apple silicon, macOS 14+, Developer ID signed, notarized and stapled ZIP.
- iPhone/iPad and Mac: 0.1.1 (2) is Testing in the existing owner-only TestFlight group. No public App Store launch or external beta expansion.
- Windows: x64 bundled-runtime MSI and EXE, package version 0.1.1. **Unsigned**, as with the preceding release.
- Android: signed APK, Android 8+, versionCode 2, using the existing signer. No Internet, camera, microphone, broad-storage permission or OS backup was added.

Validation includes 24 Apple tests and crash recovery, original Camera Stats database compatibility, actual in-place iPhone/iPad simulator upgrades, 20 Windows JVM tests and a real old-MSI-to-new-MSI upgrade retaining synthetic reports/preferences, Android native tests on phone/tablet emulators, exact signed old-APK-to-new-APK upgrades on both sizes, native PDF rendering, Swift reading Windows-exported reports, and website responsive/redirect checks. See [rebrand evidence](../REBRAND.md).

The released app implementation/resources were built from `302067f0b7fd3232594fe358a9209ca746f731ff`. Later source adds compatibility tests, test harness repair, release documentation and the website without changing those app sources/resources. SHA256SUMS accompanies the assets. The Windows runtime's corresponding OpenJDK source, upstream metadata and original checksum are also attached; retain its bundled license files.

The new site is https://shotreporter.squidproductions.org/. The previous camerastats address redirects while preserving paths and query strings. The repository is https://github.com/OfficialSquidProductions/shot-reporter; its prior URL and existing release assets remain compatible. Historical Camera-Stats-named binaries are retained rather than silently replaced.

Physical-device field acceptance and interactive owner Mac validation remain useful. Footage playback, RAW decoding, slate OCR, physical media renaming, NLE adapters and camera/NLE certification remain outside this alpha and were not implemented in this rebrand.
