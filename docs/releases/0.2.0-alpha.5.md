# Shot Reporter 0.2.0-alpha.5 — Mac candidate, build 8

This combined candidate contains the pending bug/crash reporter and the new Settings naming interface. It supersedes the unpublished reporting-only build 7. It is not yet approved for publication: native RAW reopen/bookmark and genuine signed update/relaunch acceptance remain required. The established channel is Mac Apple Silicon desktop alpha, macOS 14 or later.

- Settings appears immediately above Local Desktop Alpha. Command-comma opens it; Escape closes it.
- Movie omits season and episode controls and generated naming components. TV / Episodic enables them. Component selections, source templates, customizations and hidden metadata survive switching and relaunch.
- Historical saved presets retain independent customizations. Report exports and footage preflight use the selected settings. Draft report exports retain a safe fallback name when naming metadata is incomplete.
- Reviewed bug and crash reports use alexanderhosier@squidproductions.org. Nothing is sent automatically. Copy and text export are available, and user-entered descriptions should be reviewed before sharing.
- Local diagnostics use bounded, expiring allowlisted information and generic fatal markers. Project/media contents, private paths, raw exception text, environment variables and raw crash dumps are excluded from automatic diagnostics.
- The signed updater retains authenticated feed/archive checks and refuses installation while accepted reports cannot be verified durable or media journals are busy.

Older strict report clients reject the new optional naming-settings field rather than silently discarding it. Preserve a backup when exchanging reports with older apps. Source footage remains unchanged; OCR and NLE conform remain unfinished. Vendor RAW tools are separately installed, not bundled.

Windows and Android binaries are unchanged. iOS shared-source compilation is checked; this candidate does not authorize device runtime claims, TestFlight or App Store publication. The inactive production feed and existing download page must stay unchanged until the remaining release gates pass. Signing, notarization and automated tests alone do not replace native upgrade acceptance.
