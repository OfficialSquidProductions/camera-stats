Shot Reporter Windows desktop codec tools

FFmpeg 9.0.2 is distributed as independent command-line executables, licensed
under LGPL version 2.1 or later, using a minimal build without GPL/nonfree
components, network access or automatic dependency detection. Shot Reporter
uses these tools through child processes and does not link their libraries.

zlib 1.3.2 is statically linked into those tools under its permissive zlib license.
MinGW runtime/toolchain notices are retained in the installation's
DesktopCodecs/legal/MinGW-toolchain-notices directory. Build tools that are not
redistributed may also be described in those upstream notice files.

Full codec license texts and build configuration/hashes are installed under
DesktopCodecs/legal and DesktopCodecs/BUILD.json in the application's resources.
The matching unmodified FFmpeg and zlib source archives, rebuild script and
compiler package manifest accompany the release as
Shot-Reporter-Windows-Codec-Sources.zip. Users may replace/rebuild these separate
CLI tools; a manually chosen local decoder is supported by the desktop UI.

Original source URLs:
https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz
https://zlib.net/fossils/zlib-1.3.2.tar.gz

No RED or Blackmagic SDK/runtime/media is redistributed by this Windows package.
RAW adapters require separately installed, authorized vendor tooling. This
release does not certify Windows RED/BRAW native decoding or NLE compatibility.
Windows updates are manual while a trusted publisher certificate/feed is absent.
