Camera Stats privacy

The current Camera Stats field alpha keeps report data in local app storage and has no account system, cloud synchronization, telemetry service, advertising, or background upload.

Save As and report exports create files at a destination you choose. If you share a file through another service or storage provider, that service handles the transferred copy. A .camreport save includes report text, device attribution, and history; review it before sharing.

Export an independent backup regularly. Deleting the app or losing a device can remove local reports. A report file does not back up footage.

This local website draft uses no analytics scripts or embedded third-party content. Hosting and download services may process ordinary connection information under their own policies when the final download page is published.
